# Garaj Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Telefonda tarayıcıdan oynanan, Kerem'in 12 yaşından galericiliğe uzanan hızlı tempolu ikinci el alım-satım oyunu.

**Architecture:** Oyun kuralları `src/game/` altında React'ten bağımsız saf TypeScript fonksiyonlarıdır; tek bir `GameState` nesnesi `gameReducer` ile güncellenir ve her işlemden sonra localStorage'a yazılır. Arayüz `src/ui/` altında React bileşenleridir; durumu `useGame()` hook'u üzerinden okur, `dispatch` ile eylem gönderir. Rastgelelik durum içinde saklanan tohumlu bir üreteçle yapılır, böylece testler tekrarlanabilir.

**Tech Stack:** Vite, React 18, TypeScript, Vitest, @testing-library/react, vite-plugin-pwa. Düz CSS (CSS değişkenleri), UI kütüphanesi yok.

**Spec:** `docs/superpowers/specs/2026-11-23-garaj-design.md`

## Global Constraints

- Dil Türkçe, para birimi TL. Tutarlar `Intl.NumberFormat('tr-TR')` ile biçimlenir: `1.250.000 TL`.
- Gerçek araç/motor/eşya markası ismi veya logosu yok; markalar hayali.
- Dikey telefon ekranı, 360–430 px genişlik; masaüstünde en fazla 430 px genişlikte ortalı.
- Dokunma alanları en az 44 px.
- Bekleme süresi, enerji sistemi, gerçek zamanlı zamanlayıcı yok.
- Kayıt yalnızca localStorage'da; sunucu, hesap, reklam, ses yok.
- Başlangıç: 12 yaş, 2.000 TL, 1. aşama.
- Aşama geçişleri: 50.000 TL → 2. aşama (16 yaş), 500.000 TL → 3. aşama (18 yaş).
- Depolama: 1. aşama 3 eşya, 2. aşama 2 motor, 3. aşama garaj kapasitesi (1 → 2 → 4 → 8).
- Koyu tema, tek vurgu rengi, kart tabanlı; alt sekmeler: İlanlar, Garaj, Satış, Profil.

## Review Focus

1. **Bozuk veya eski kayıt** (JSON hatası, farklı `version`): oyun çökmez, "Kayıt okunamadı — Yeni oyun" ekranı çıkar. → Task 7 testi.
2. **Para yetmeyen gider** (maaş, faiz): para eksiye düşmez; maaşı ödenemeyen çalışan ayrılır, ödenemeyen faiz borca eklenir. → Task 6 testi.
3. **Dolu depo veya yetersiz para ile alım**: işlem reddedilir, durum değişmez, kullanıcıya sebep gösterilir. → Task 3 testi.
4. **Çift dokunma** (aynı teklifi iki kez kabul, aynı ilanı iki kez alma): ikinci eylem durumu değiştirmez. → Task 7 testi.
5. **Uzun isimler ve büyük sayılar** 360 px ekranda taşmaz (`12.500.000 TL`, uzun marka+model). → Task 8 testi.
